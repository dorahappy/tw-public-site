# TW的旅行日记

仓库：[`dorahappy/tw-public-site`](https://github.com/dorahappy/tw-public-site)。这是两个人的静态旅行日记网站，原生 HTML/CSS/JavaScript，无框架、无依赖、无需编译。

## 页面与素材

- `/`：首页，介绍 TW 的含义，区分出发前准备与归来实拍攻略。
- `/travel/`：欧洲出发前准备手册。保留原地址、行程、打包勾选、待办与手机日历；此页记录当时的计划。
- `/travel-notes/`：意大利与法国归来攻略。保留完整经历正文、22 张实拍照片、路线图和键盘可操作的大图查看器。
- `public/site-assets/brand.css`：三页共用品牌、配色与组件样式。默认明亮，跟随系统深色模式；准备页也保留可用的主题切换。
- `public/travel-notes/travel-guide-assets/`：44 个网页照片/缩略图及 2 张路线图，共 46 个资源。照片已移除 EXIF/GPS，原图与本地素材清单不在仓库中。

TW 取自夫妻名字里各一个字的首字母。首页及归来攻略使用旅途实拍；旧准备页相册中的旅行氛围示意图仍明确标注为生成图，不冒充实拍。

首页双人旅行插画由内置图片生成工具制作，提示：透明背景、手绘风格的两位成年旅客，背包、行李箱、地图，蓝色、珊瑚色与黄色配色。插画仅作装饰，不对应或推断真人外貌。

## EdgeOne 设置

| 设置 | 值 |
| --- | --- |
| 项目根目录 | `.` |
| 构建命令 | `test -f public/index.html` |
| 输出目录 | `public` |
| 生产分支 | `main` |

根目录的 `edgeone.json` 会覆盖对应控制台设置。构建命令只验证首页存在，不安装依赖或编译。公开范围仅为 `public/`，不包含原始资料、账本或服务凭据。

## 本地查看

在仓库目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory public
```

打开 `http://127.0.0.1:8000/`。验证首页、两篇手册、日夜配色和手机布局；停止服务按 Ctrl+C。

## 更新内容

保持 `/travel/` 与 `/travel-notes/` 的现有地址。新增页面可使用 `public/<slug>/index.html`，加入首页入口与返回首页链接，引用共享品牌 CSS。

更新归来攻略时保留完整正文、景点与照片对应关系、路线图和可用的大图查看器。更新准备手册时保留清单勾选与日历功能，并明确其“当时计划”的性质。每次公开前检查金额、私有文件、凭据和无效链接；只加入已确认可公开的内容。

归来攻略在保留完整故事与实拍照片的基础上，加入少量漫画便签、原句重点和复用双人贴纸作为阅读辅助，支持系统深色模式与打印。

归来攻略的“住宿怎么订”章节记录平台比价、官网邮件询房与 offer 确认流程，并提醒付款前核对取消退款条款；桌面与手机目录均可直达，不展示定金金额。

本站品牌为“TW的旅行日记”，本次旅行系列为“TW的旅行日记 - 欧洲篇”；现有 `/travel/` 与 `/travel-notes/` 分别为本篇出发前手册和归来攻略。未来新旅行可新增独立目录并在首页按旅行系列组织入口，保留欧洲篇原链接。归来攻略手机端使用可收起的顶部小旅伴目录，正文主题标签不替代原文。

欧洲篇新增 `/europe-scenery/` 路线与风景页：首页第三入口展示 49 张用户提供的 DJI 实拍照片，WebP 素材共约 6.66 MiB（原 24 张保留，新增 25 张经全量联系表与候选大图筛选，优先风景、建筑与背影）。路线海报以实拍富内斯照片为底，原生 SVG 依据 Natural Earth / world-atlas 国家轮廓与统一 Mercator 投影绘制；米兰、多洛米蒂、佛罗伦萨、罗马、巴黎、米兰为实际顺序，连线不表示实际道路或航路。页面内嵌样式与脚本，支持点击城市跳转、放大路线、照片键盘与触摸浏览，无外部运行时依赖。照片原件保持不变。

路线页国界采用 [world-atlas](https://github.com/topojson/world-atlas) 的 Natural Earth 1:50m 数据，仅将法国欧洲部分与意大利的国家轮廓内联到 HTML；完整地理数据源不公开打包。
