# 双晓静态站点

独立的多页面静态网站，无框架、无依赖、无需编译。当前仅在本地准备；没有关联远程仓库或执行发布。

## EdgeOne Makers / Pages 设置

| 设置 | 值 |
| --- | --- |
| 项目根目录 | `.` |
| 构建命令 | `test -f public/index.html`（由 `edgeone.json` 指定） |
| 输出目录 | `public` |
| 生产分支 | `main` |

仓库中的 `edgeone.json` 会覆盖对应控制台设置：输出目录为 `public`，构建命令为
`test -f public/index.html`，仅验证首页存在，不安装依赖或编译文件。

只将本目录作为独立 Git 仓库导入。公开文件范围为 `public/`。

## 页面

- `/`：内容首页。
- `/travel/`：无金额旅行手册，含五张旅行图片和日历文件。

分享页仍保留公开分享所需的行程、酒店及日历内容。此仓库不包含账本页面、原始资料或服务凭据。

## 本地查看

在本目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory public
```

浏览器打开 `http://127.0.0.1:8000/`。停止服务按 Ctrl+C。

## 新增内容

1. 新建 `public/<slug>/index.html`，例如 `public/notes/index.html`。
2. 图片等资源放在该页面目录中，使用相对链接引用。
3. 子页面加入 `<a href="../">返回首页</a>`。
4. 在 `public/index.html` 添加对应 `<slug>/` 入口。
5. 提交前检查本地链接、手机布局和将要提交的文件；仅加入已确认可公开的内容。

更新旅行页时，仅同步已审核的无金额分享页面及其必要资源，并保留返回首页链接。
